## 🚀 What I'm Building

**[Semantask](https://github.com/harshlocham/semantask)** — AI-native work coordination: teams talk, AI extracts the work as suggestions, managers approve and stay in control. Autonomy is optional and policy-gated, not the default.

- 💬 Suggest-first extraction from realtime chat — review before any side effects
- ✅ Manager approvals, tool grants, org policy, and audit trails
- 🔄 Transactional outbox + idempotent, lease-based async task execution
- 🤖 Optional multi-provider LLM execution layer, gated behind explicit policy modes

Product direction: [ADR-005](https://github.com/harshlocham/semantask/blob/main/docs/decisions/ADR-005-suggest-first-work-coordination.md)

**[Knowledge Workbench](https://github.com/harshlocham/knowledge-workbench)** — NotebookLM-style research assistant with hybrid retrieval (dense + lexical, RRF-fused, LLM-reranked) and citation-grounded answers that jump back into the original source.
